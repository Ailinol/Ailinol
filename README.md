## 📌 Projetos em Andamento: Minhas Missões

### 🔹 **Sistema de Administração Escolar (UEM Project)**
Um sistema robusto para gerir pessoal escolar, certificados, relatórios e distribuição de materiais académicos.
- **Funcionalidades:** Dois níveis de acesso (Direção & Professores), armazenamento de arquivos binários, interface em Java Swing.

### 🔹 **Local Intelligent Assistant — “Semente”**
Um assistente de IA privado e local que aprende com o utilizador, mantendo-se offline.
- **Foco:** LLM engineering + personalização + privacidade.

### 🔹 **TARIMBA**
Um sistema de experiência digital para ajudar jovens sem oportunidades a exibir as suas habilidades e conseguir empregos.

### 🔹 **Product Management System (Java Swing)**
Categorias, geração automática de IDs, persistência de dados e uma GUI limpa e funcional.
